Cours interactif — TCS — Chimie : Modèle de l'atome (6 parties)
Application Android — Pr Hicham MESBAH

1. Décompresser ce dossier.
2. Android Studio > File > Open > choisir le dossier "CoursAtomeTCSAndroid".
3. Attendre la synchronisation Gradle (connexion Internet nécessaire la première fois).
4. Build > Build App Bundle(s) / APK(s) > Build APK(s).
   L'APK se trouve dans : app/build/outputs/apk/debug/app-debug.apk
5. Copier l'APK sur le téléphone et l'installer (autoriser « sources inconnues »).

Pour modifier le cours : remplacer app/src/main/assets/index.html puis recompiler.
Android 8.0 (API 26) minimum. Le cours fonctionne hors ligne
(sans Internet, les polices sont remplacées par des polices du système).
