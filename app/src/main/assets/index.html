Constitution de l'atome

✎ Pr Hicham MESBAH · TCS
1

Le noyau et les électrons

Pr Hicham MESBAH

L'atome est constitué :

  • d'un noyau central, formé de protons et de neutrons ; on les appelle des nucléons ;
  • d'électrons qui se déplacent autour du noyau.

Le proton est positif, l'électron est négatif, le neutron est neutre (d'où son nom). Le proton et le neutron ont presque la même masse.
3

Masse de l'atome

Pr Hicham MESBAH
Calcul
mp / me = 1,673 × 10⁻²⁷ / 9,1 × 10⁻³¹ ≈ 1840

La masse des électrons est négligeable devant celle des nucléons. La masse de l'atome est donc concentrée dans son noyau : matome ≈ A × mp (A = nombre de nucléons).

4

Neutralité électrique

Pr Hicham MESBAH

L'atome est électriquement neutre car il contient autant de protons que d'électrons.

À retenir

Charge du noyau : +Z·e ; charge des électrons : −Z·e ; charge totale : 0.

✎ Pr Hicham MESBAH · TCS
1

Le symbole AZX

Pr Hicham MESBAH
Notation
AZX

A : nombre de masse ; Z : numéro atomique ; X : symbole de l'élément.

Signification
  • Z représente le nombre de protons ;
  • A représente le nombre de nucléons ;
  • nombre de neutrons : N = A − Z ;
  • nombre d'électrons d'un atome neutre : Z.
Astuce : la charge d'un ion ne modifie que les électrons. Pour Xn+ : Z − n électrons (il en a perdu n) ; pour Xn− : Z + n électrons (il en a gagné n). Le noyau (Z, A, N) ne change jamais.

Dimensions de l'atome

✎ Pr Hicham MESBAH · TCS
1

Atome et noyau

Pr Hicham MESBAH
  • Rayon de l'atome : ratome ≈ 10⁻¹⁰ m
  • Rayon du noyau : rnoyau ≈ 10⁻¹⁵ m
Calcul
ratome / rnoyau = 10⁻¹⁰ / 10⁻¹⁵ = 10⁵

L'atome est donc environ 100 000 fois plus grand que son noyau. Si le noyau avait la taille d'une bille de 1 cm, l'atome aurait un rayon de 1 km.

Animation 5 : Zoom de l'atome jusqu'au noyau
2

La structure lacunaire — l'expérience de Rutherford (1911)

Pr Hicham MESBAH

Rutherford a bombardé une très fine feuille d'or avec des particules α (positives). Presque toutes traversent la feuille sans être déviées : l'atome est presque vide. Quelques-unes, qui passent très près d'un noyau, sont fortement déviées, voire renvoyées.

Animation 6 : Bombardement d'une feuille d'or par des particules α
Conclusion

La matière a une structure lacunaire : entre le noyau et les électrons, il y a essentiellement du vide.

Élément chimique, isotopes et ions

✎ Pr Hicham MESBAH · TCS
1

Élément chimique

Pr Hicham MESBAH

Un élément chimique est l'ensemble des entités (atomes ou ions) qui ont le même numéro atomique Z. Au cours d'une transformation chimique, les éléments chimiques se conservent.

Exemple : Na, Na⁺, ²³Na appartiennent tous à l'élément sodium (Z = 11). Le cuivre métallique Cu et l'ion Cu²⁺ sont le même élément cuivre (Z = 29).
2

Les isotopes

Pr Hicham MESBAH

Des isotopes sont des atomes qui ont le même nombre de protons mais des nombres de neutrons différents.

3

Les ions monoatomiques

Pr Hicham MESBAH
  • Un atome qui perd un ou plusieurs électrons devient un ion positif appelé cation.
  • Un atome qui gagne un ou plusieurs électrons devient un ion négatif appelé anion.
Exemple : l'atome de sodium Na perd 1 électron et devient l'ion Na⁺ ; l'atome de chlore Cl gagne 1 électron et devient l'ion Cl⁻.
Animation 8 : Formation d'un ion
Astuce : perdre des électrons (négatifs), c'est comme effacer des dettes : le « solde » devient positif. Gagner des électrons rend l'ion négatif.

Partie V · Chimie TCS

Répartition électronique (Z ≤ 18)

✎ Pr Hicham MESBAH · TCS
1

Les couches électroniques

Pr Hicham MESBAH

Les électrons se répartissent sur des couches notées K (n = 1), L (n = 2), M (n = 3)… Une couche de numéro n contient au maximum 2n² électrons.

CoucheKLM
n123
Nombre maximal d'électrons2818
Pour Z ≤ 18 (programme du Tronc Commun), la couche M ne reçoit pas plus de 8 électrons.
2

Règles de remplissage

Pr Hicham MESBAH
  • Les couches se remplissent dans l'ordre : K → L → M ;
  • on ne commence à remplir une couche que si la précédente est saturée ;
  • la dernière couche occupée s'appelle la couche externe ; ses électrons sont les électrons de valence.
Exemple : sodium Na (Z = 11) : formule électronique (K)²(L)⁸(M)¹.
À toi : magnésium Mg (Z = 12) : (K)²(L)⁸(M)²

Partie VI · Chimie TCS

Exercice de synthèse

✎ Pr Hicham MESBAH · TCS
✎

Énoncé

Pr Hicham MESBAH

Le noyau d'un atome X porte une charge q = 2,08 × 10⁻¹⁸ C et contient 14 neutrons.
Données : e = 1,6 × 10⁻¹⁹ C ; mp ≈ mn ≈ 1,67 × 10⁻²⁷ kg.

1. Calculer le numéro atomique Z de cet atome.
Afficher la solution

Le noyau contient Z protons de charge +e : q = Z·e, donc Z = q/e = 2,08 × 10⁻¹⁸ / 1,6 × 10⁻¹⁹ = 13.

2. En déduire le nombre de masse A et écrire le symbole du noyau (X = Al).
Afficher la solution

A = Z + N = 13 + 14 = 27 ; symbole : 2713Al.

3. Calculer la masse approchée de l'atome. Justifier l'approximation.
Afficher la solution

m ≈ A × mp = 27 × 1,67 × 10⁻²⁷ ≈ 4,5 × 10⁻²⁶ kg. On néglige la masse des électrons, environ 1840 fois plus faible que celle d'un nucléon.

4. Écrire la formule électronique de cet atome et donner son nombre d'électrons de valence.
Afficher la solution

13 électrons : (K)²(L)⁸(M)³ ; couche externe M avec 3 électrons de valence.

5. L'atome perd ses électrons de valence. Donner le symbole de l'ion formé et sa charge.
Afficher la solution

Il perd 3 électrons : ion Al³⁺ ; q′ = +3e = 3 × 1,6 × 10⁻¹⁹ = 4,8 × 10⁻¹⁹ C.

Je retiens

Pr Hicham MESBAH
L'essentiel
  • L'atome = un noyau (Z protons + N neutrons) + Z électrons ; il est électriquement neutre.
  • Notation AZX : A = nombre de nucléons, Z = nombre de protons, N = A − Z.
  • Masse de l'atome ≈ masse du noyau ≈ A × mn.
  • Structure lacunaire : ratome ≈ 10⁻¹⁰ m, rnoyau ≈ 10⁻¹⁵ m.
  • Isotopes : même Z, A différent. Un élément chimique est caractérisé par Z.
  • Répartition électronique : K (2), L (8), M (8 pour Z ≤ 18), dans l'ordre K → L → M.
